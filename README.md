# Stream Notify

Нативный док-плагин для OBS 33.0.0 x64: анонсы стримов в Telegram/Discord и экспериментальные интеграции донатов.

## Последнее обновление
- Компактный режим включён по умолчанию для новых настроек и файлов без поля compact. Существующий выбор сохраняется.
- В пакет включён Qt Schannel TLS backend. Плагин регистрирует его каталог до сетевых запросов.
- HTTPS из упакованной копии проверен без ключей: Telegram HTTP 302, Discord HTTP 200, с проверкой сертификатов.
- Начало эфира определяется по общему состоянию OBS и сетевых выходов, включая сервисные выходы Aitum Multistream.
- Первый активный выход начинает сессию, дополнительные выходы не дублируют анонс. Сессия заканчивается после остановки последнего выхода.
- Новые динамические выходы обнаруживаются проверкой раз в секунду. Запись, replay buffer и виртуальная камера исключены.
- При загрузке плагина в уже активный эфир ретроспективный анонс не отправляется.
- Только во время стрима в модуле донатов использует то же агрегированное состояние.
- Пройдены тесты порогов/валют, Telegram-ссылок, навигации, языка и моделируемых сценариев нескольких выходов.

Интеграцию с реальным Aitum и отправку вашим ботом/webhook нужно проверить локально.
DonatePay остаётся экспериментальным: API-ключ вводится только в программе; формат валюты и работа на реальном аккаунте требуют проверки.

## Установка и обновление
Полностью закройте OBS. Замените папку stream-notify в C:\ProgramData\obs-studio\plugins\ папкой из ZIP.
Копируйте всю папку, включая bin и data, а не только stream-notify.dll.
Проверка структуры:
- stream-notify/bin/64bit/stream-notify.dll
- stream-notify/bin/64bit/Qt6WebSockets.dll
- stream-notify/data/qt-plugins/tls/qschannelbackend.dll

Настройки хранятся отдельно. Если compact=false уже сохранён, включите режим вручную в Интерфейс.
Запустите OBS → Док-панели → Stream Notify. Сначала проверьте ручные тесты Telegram/Discord, затем непубличный эфир через Aitum.
Для двух выходов должен быть один отсчёт; остановка одного не завершает сессию.
Следующий запуск после полной остановки должен создать новый отсчёт.
