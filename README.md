# Stream Notify

Нативный док-плагин для OBS 33.0.0 x64: анонсы стримов в Telegram/Discord и экспериментальные интеграции донатов.

[Скачать актуальную тестовую DLL](https://github.com/DIMI0007/stream-notify/actions/runs/40076919576/artifacts/12553618173) ·
[Сборка и проверки](https://github.com/DIMI0007/stream-notify/actions/runs/40076919576) ·
[Снимки Qt-интерфейса](https://github.com/DIMI0007/stream-notify/actions/runs/40076919576/artifacts/12553159921)

## Последнее обновление
- Компактные карточки, переключатели, значки сервисов и активные вкладки по прототипам.
- Страница донатов с получателями, рублёвыми порогами, шаблонами, предпросмотром и журналом.
- Смена языка и страниц пересоздаёт виджеты после завершения события Qt.
- В поле канала Telegram принимаются @имя, публичная ссылка и ссылка на сообщение приватного канала t.me/c/….
- Инструкция подключения в программе; диагностика сети скрывает токены и URL.
- Сборка, тесты порогов/валют, ссылок Telegram и Qt-проверка языка/навигации пройдены.
- Девять снимков интерфейса получены из рабочего Qt-кода без реальных токенов и отправок.

Первоначальная DLL была загружена пользователем в OBS 33. Последние изменения проверены в отдельном Qt-окне; повторная проверка внутри OBS требуется.
Ошибка Telegram network 99 требует проверки реального соединения. DonatePay остаётся экспериментальным.

## Установка и обновление
Полностью закройте OBS. Замените папку stream-notify в C:\ProgramData\obs-studio\plugins\ папкой из ZIP.
Должен существовать путь C:\ProgramData\obs-studio\plugins\stream-notify\bin\64bit\stream-notify.dll.
Не переносите туда внешнюю папку с названием ZIP. Пользовательские настройки хранятся отдельно.
Запустите OBS → Док-панели → Stream Notify.
