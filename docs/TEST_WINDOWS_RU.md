# Stream Notify — установка и тестирование

Поддерживаемая тестовая конфигурация: **Windows x64, OBS 33.0.0, Qt 6.11.1**.
Для других версий OBS совместимость проверяется отдельно.

## Скачать
Откройте Actions → Build Stream Notify test DLL (Windows), выберите последнюю успешную сборку и скачайте:
**StreamNotify-Test-DLL-OBS33-Windows-x64**.
Артефакт StreamNotify-UI-Previews содержит снимки из тестового Qt-окна и не предназначен для установки.

## Установить или обновить
1. Полностью закройте OBS.
2. Распакуйте ZIP.
3. Скопируйте папку stream-notify в `C:\ProgramData\obs-studio\plugins\`.
4. При обновлении сначала удалите старую папку `stream-notify`, затем скопируйте новую целиком. Локальные настройки хранятся отдельно.
5. Запустите OBS → Док-панели → Stream Notify.

Структура:
```text
plugins/
  stream-notify/
    stream-notify.dll
    Qt6WebSockets.dll
    data/qt-plugins/tls/qschannelbackend.dll
```
Копирование только stream-notify.dll недостаточно. Нельзя оставлять внешнюю папку с именем ZIP.
ProgramData скрыта: откройте путь через Win+R. Расположение DLL прямо в папке плагина соответствует новому формату OBS 33.
PDB нужен для диагностики; SHA256.txt содержит контрольные суммы DLL.

## Telegram
1. Получите токен своего бота в @BotFather и введите только в плагине.
2. Добавьте бота в администраторы канала с правом публикации сообщений.
3. Укажите @имя, публичную ссылку t.me/имя или ID.
4. Для приватного канала можно вставить ссылку на сообщение t.me/c/…; ссылка-приглашение не подходит.
5. Включите отправку и нажмите «Отправить тест». Эфир не нужен.

## Discord
Создайте webhook в настройках нужного канала Discord → Интеграции → Вебхуки.
Вставьте URL локально, включите Discord и отправьте тест.
Переключатель **«Упоминать @everyone»** по умолчанию выключен.
Во включённом состоянии тег добавляется отдельной строкой в конец Discord-сообщений: анонсов, донатов и ручных тестов.
Telegram этот переключатель не затрагивает. Итоговый Discord-текст вместе с тегом должен укладываться в 2000 символов.

## Стрим и Aitum
Укажите постоянные ссылки YouTube/Twitch и шаблон. Запустите непубличный эфир через OBS или Aitum.
Проверка новых сетевых выходов выполняется раз в секунду.
Первый активный выход запускает отсчёт. Следующие выходы не дублируют анонс.
Остановка одного выхода не завершает сессию, пока другой работает.
После полной остановки новый запуск создаёт новую сессию.
Запись, replay buffer и виртуальная камера не должны запускать рассылку.
При загрузке плагина во время уже активного эфира ретроспективный анонс не отправляется.

## Донаты
Включите модуль и настройте сервисы/получателей. Начните с ручного теста.
Ручной тест проверяет отправку сообщения; приём реального доната проверяется отдельно.
[Статус интеграций](../README_DONATIONS_RU.md), [рублёвые пороги и курсы](CURRENCY_RU.md).

## Диагностика
- Нет панели: проверьте путь без лишней вложенной папки. Затем Справка → Файлы журнала → текущий журнал, поиск Stream Notify / Failed to load.
- TLS initialization failed: проверьте data/qt-plugins/tls/qschannelbackend.dll и замените весь пакет. Не отключайте проверку сертификатов.
- HTTP 401/403: проверьте локальные ключи и права канала.
- Ошибка сети: проверьте доступ к сервису, интернет и настройки VPN/прокси.

Смена языка и страниц проверяется в отдельном Qt-окне CI; работу внутри OBS следует проверять после обновлений.
Для отключения: закройте OBS и удалите только папку stream-notify из plugins.
