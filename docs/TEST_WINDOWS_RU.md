# Первая тестовая DLL Stream Notify

Сборка: Windows x64, OBS 33.0.0, Qt из obs-deps 2026-10-23.
Проверка компиляции не подтверждает работу внутри OBS. Для первого теста используйте OBS 33.0.0 x64, желательно отдельную portable-копию.
Другие версии OBS требуют отдельной проверки совместимости Qt/ABI.

## Получение
Откройте Actions → Build Stream Notify test DLL (Windows).
После успешной сборки скачайте артефакт StreamNotify-Test-DLL-OBS33-Windows-x64.
Архив должен содержать stream-notify/bin/64bit/stream-notify.dll и Qt6WebSockets.dll.
PDB нужен для диагностики, не для запуска. SHA256.txt содержит контрольные суммы.

## Установка
1. Полностью закройте OBS.
2. Скопируйте папку stream-notify из архива в C:\ProgramData\obs-studio\plugins\.
3. Запустите OBS. Откройте Доки → Stream Notify.
4. При проблемах откройте Справка → Файлы журнала → Просмотреть текущий журнал и найдите Stream Notify / Failed to load.
Не заменяйте Qt6Core.dll и другие библиотеки самого OBS.

## Первый тест без секретов
Проверьте появление панели, вкладки настроек (включая Донаты), RU/EN, сохранение несекретных настроек и повторный запуск OBS.
Переключайте вкладки, закройте и снова откройте док. Проверьте завершение OBS без зависания.

## Проверка отправки
Токены и webhook вводятся только локально в настройках плагина. Не загружайте settings.json, журналы донатов или секреты в GitHub и чат.
Используйте свои тестовые Telegram/Discord-каналы. Сначала ручной тест, затем непубличный эфир: начало, отсчёт, отмена, завершение и повторное начало эфира.
Проверьте отсутствие повторной рассылки после смены сцены и переподключения.
DonationAlerts проверяется отдельно после настройки локального OAuth-токена.
DonatePay использует экспериментальный legacy-адаптер, выключенный по умолчанию; актуальная схема API ещё требует проверки на аккаунте.

## Отключение
Закройте OBS и удалите C:\ProgramData\obs-studio\plugins\stream-notify.
Настройки хранятся отдельно в конфигурации OBS. Секреты защищаются Windows DPAPI и привязаны к пользователю Windows.

Для компиляции нужен только GitHub Actions. Telegram, Discord, DonationAlerts и DonatePay подключать к Codex или добавлять в Actions Secrets не требуется.

## Исправление TLS initialization failed
Архив включает data/qt-plugins/tls/qschannelbackend.dll из той же сборки Qt 6.11.1.
Копируйте папку stream-notify целиком, включая data. Не копируйте только DLL из bin.
Проверка CI изолирует пути Qt-плагинов и делает HTTPS-запрос к api.telegram.org без токена и без отправки сообщений.
Это подтверждает TLS в пакете; отправку вашим ботом нужно отдельно проверить локальной кнопкой теста.
