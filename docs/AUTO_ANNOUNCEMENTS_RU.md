# Автоматические ссылки Stream Notify

## Настройка

1. В разделе «Связь» включите Telegram и/или Discord и проверьте тестовую отправку.
2. Для определения эфиров войдите в YouTube и Twitch на той же странице. Для Kick укажите ссылку на канал или включите Kick в Stream Chat и сохраните там имя канала. Если Stream Chat уже подключён под вашим аккаунтом Windows, Stream Notify может читать его защищённые токены Twitch и YouTube и имя канала Kick для проверки статуса. Данные Stream Chat плагин не изменяет.
3. При желании укажите ручные ссылки Twitch, YouTube и Kick. Они используются только при ошибке проверки или отсутствии авторизации и только когда OBS видит отдельный активный выход соответствующей платформы.
4. В разделе «Сообщение» выберите задержку 60, 90, 120 или 360 секунд. Для новых установок задано 120 секунд.
5. Там же включите или выключите анонс платформы, которая запустилась позже, и отредактируйте его шаблон. Это работает и для второй, и для третьей платформы.

## Поведение

- После запуска потока OBS платформы проверяются раздельно. YouTube и Twitch подтверждаются официальными API. Kick проверяется по публичной странице канала. Общий статус OBS сам по себе не подтверждает Twitch, YouTube или Kick.
- На YouTube используется ссылка на текущий Video ID. На Twitch — ссылка на канал, а Stream ID используется для защиты от повторов. Для Kick используется ссылка и идентификатор текущего эфира канала.
- Приватный эфир YouTube не анонсируется. Публичный и доступный по ссылке эфир может быть анонсирован.
- При запуске второй или третьей подтверждённой платформы после основного анонса дополнительное сообщение уходит во все включённые мессенджеры.
- Перед каждой отправкой сохраняется запись по платформе, идентификатору эфира, типу сообщения и получателю. Неопределённый результат доставки автоматически не повторяется.
- Запросы идут асинхронно и разнесены по времени; проверка во время ожидания происходит раз в 20 секунд, после основной отправки — раз в минуту.

## Переменные шаблона

Основной шаблон: `{youtube}`, `{twitch}`, `{kick}`, `{youtube_url}`, `{twitch_url}`, `{kick_url}`, `{stream_url}`. В дополнительном шаблоне доступна также `{platform}`. Строки с неактивной платформой удаляются.

## Ограничение ручной ссылки

Когда проверка платформы недоступна, ручная ссылка не даёт уникальный Stream ID. Одна и та же ссылка на канал может использоваться в нескольких эфирах, поэтому автоматическая защита от дублей не может одновременно гарантировать новый анонс каждого такого эфира. Для полной проверки нового эфира настройте проверку платформы.
