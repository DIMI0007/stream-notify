# Автоматические ссылки Stream Notify

## Настройка

1. В разделе «Связь» включите Telegram и/или Discord и проверьте тестовую отправку.
2. Для определения эфиров войдите в YouTube и Twitch на той же странице. Если Stream Chat уже подключён под вашим аккаунтом Windows, Stream Notify может читать его защищённые токены для проверки статуса. Токены Stream Chat плагин не изменяет.
3. При желании укажите ручные ссылки. Они используются только при ошибке API или отсутствии авторизации и только когда OBS видит отдельный активный выход соответствующей платформы.
4. В разделе «Сообщение» выберите задержку 60, 90, 120 или 360 секунд. Для новых установок задано 120 секунд.
5. Там же включите или выключите анонс второй платформы и отредактируйте его шаблон.

## Поведение

- После запуска потока OBS плагины платформ проверяются раздельно. Подтверждение YouTube и Twitch дают официальные API; общий статус OBS сам по себе не подтверждает обе платформы.
- На YouTube используется ссылка на текущий Video ID. На Twitch — ссылка на канал, а Stream ID используется для защиты от повторов.
- Приватный эфир YouTube не анонсируется. Публичный и доступный по ссылке эфир может быть анонсирован.
- При запуске второй подтверждённой платформы после основного анонса дополнительное сообщение уходит во все включённые мессенджеры.
- Перед каждой отправкой сохраняется запись по платформе, идентификатору эфира, типу сообщения и получателю. Неопределённый результат доставки автоматически не повторяется.
- Запросы идут асинхронно и разнесены по времени; проверка во время ожидания происходит раз в 20 секунд, после основной отправки — раз в минуту.

## Переменные шаблона

Основной шаблон: `{youtube}`, `{twitch}`, `{youtube_url}`, `{twitch_url}`, `{stream_url}`. В дополнительном шаблоне доступна также `{platform}`. Строки с неактивной платформой удаляются.

## Ограничение ручной ссылки

Когда API недоступен, ручная ссылка не даёт уникальный Stream ID. Для Twitch одна и та же ссылка на канал может использоваться в нескольких эфирах, поэтому автоматическая защита от дублей не может одновременно гарантировать новый анонс каждого такого эфира. Для полной проверки нового эфира подключите API.
