# Пороги донатов в рублях

Все три порога задаются в RUB (по умолчанию 100 / 500 / 2000).
Для выбора уровня сумма умножается на сохранённый курс RUB за одну единицу исходной валюты.
В сообщении остаются исходная сумма и валюта.
Пример: 1 USD при курсе 90 RUB/USD не проходит порог 100 RUB; 2 USD проходят.

Плагин при первом включении модуля донатов запрашивает один снимок из
https://www.cbr-xml-daily.ru/daily_json.js — стороннего JSON-сервиса с курсами ЦБ.
При неудаче можно нажать «Загрузить / обновить курсы».
В файле exchange-rates.json в каталоге конфигурации плагина сохраняются источник,
дата котировки и rub_per_unit (курс Value / Nominal).
Существующий файл автоматически не обновляется. Явное обновление доступно кнопкой.
Настройки донатов показывают дату и число валют. Файл можно редактировать при закрытом OBS.

RUB работает без файла. Валюты, которых нет в таблице, а также отсутствующая валюта
в событии пропускаются. Переполнение, отрицательная сумма или некорректный курс
также не создают отправку. Старые отдельные пороги USD/EUR больше не используются.
Проверки до загрузки курсов не переигрываются автоматически.

DonatePay пока экспериментальный: имя берётся из what, учитываются только
type=donation и status=success. Документация пользователя не подтверждает поле
валюты и полный URL запроса; при отсутствии валюты отправка блокируется.
Опрос последних 100 записей пока не гарантирует полноту при большом потоке.
WebSocket-подключение по документации известно, формат payload ещё не проверен.
