# Service brand artwork

The DonationAlerts and DonatePay marks identify supported integrations.
They remain trademarks of their respective owners; inclusion does not imply endorsement.

Official brand pages:
- DonationAlerts: https://www.donationalerts.com/brand
- DonatePay: https://donatepay.ru/page/brand

Retrieved 2026-10-24 from:
- https://www.donationalerts.com/img/brand/da.svg
- https://donatepay.ru/build/assets/logo-new-mini-2dbd7bd3.svg

The original DonationAlerts download is gzip-compressed SVG and is retained as
donationalerts.svgz. DonatePay's original SVG is retained as donatepay.svg.
The PNGs were rendered from these original marks at 256 × 256 with CairoSVG 2.8.2.
The full marks, colours and aspect ratios are preserved, including transparent padding.
Only PNGs are embedded in the DLL; no SVG runtime plugin or network request is needed.

The dock displays these images in the same 28 × 28 logical-pixel footprint as the
other service badges, with padding on an official dark brand background.
