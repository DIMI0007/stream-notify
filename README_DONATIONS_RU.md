# Stream Notify 1.0 — модуль донатов (версия исходного кода)

## Статус разработки

**Реализован исходный код, но DLL и установщик Windows пока не собраны и не проверены внутри OBS.** Успешно выполнены автономные тесты алгоритма уровней донатов, а также структурные проверки исходников. Эти проверки не заменяют проверку API и сборку C++/Qt на Windows.

## Что добавлено

- Вкладка «Настройки → Донаты» с независимыми настройками DonationAlerts/DonatePay и Telegram/Discord.
- Общий мастер-переключатель, «Только во время стрима» (по умолчанию), выключение текста донатера.
- Три настраиваемых шаблона, предпросмотр, ручное тестовое сообщение.
- Отдельные пороги по валютам (по умолчанию RUB 100/500/2000, никаких автоматических конвертаций).
- Приём real-time событий через официальные `/user/oauth`, `/centrifuge/subscribe` и Centrifugo WebSocket DonationAlerts. Доступ Token должен включать `oauth-user-show` и `oauth-donation-subscribe`.
- Локальный журнал, записываемый атомарно через QSaveFile перед первым запросом доставки: статус каждого получателя сохраняется отдельно. После неожиданного завершения `inflight` становится `unknown` и не отправляется повторно автоматически.
- Существующие токены Telegram и Discord не дублируются в новом модуле; новые токены DA/DP шифруются Windows DPAPI.
- Асинхронные запросы через Qt Network, `Qt6::WebSockets` для DonationAlerts.
- Ручной тест не создаёт фиктивную запись настоящего доната в журнале.

## DonatePay: важно

Официальная документация https://donatepay.ru/page/api открывается **после входа**. Опубликованные клиентские библиотеки показывают доступность транзакций через пользовательский API-ключ и API v1, но не подтверждают действующие поля и метод авторизации на дату релиза. Поэтому адаптер `donatepay.ru/api/v1/transactions` помечен **экспериментальным и выключен по умолчанию**. Для его включения требуется отдельный флажок «старый API». Используется HTTPS и опрос через 30 секунд с увеличением интервала при сбоях. На первом успешном чтении создаётся базовая отметка, старые транзакции не отправляются.

**Не выдавайте эту часть за проверенную интеграцию DonatePay.** Перед публичным релизом надо получить документацию из реального DonatePay-аккаунта, проверить точное имя метода, заголовок/параметр авторизации, поля суммы, валюты, ID, статуса и типа операции, схему пагинации/лимитов и поведение тестовых транзакций. После этого убрать экспериментальный флажок и обновить адаптер.

Это DonatePay **donatepay.ru**, не одноимённый `donationpay.org` или `donpay.app`.

## Защита от дублей и особые случаи

- Идентификатор доната: `DonationAlerts:<id>` либо `DonatePay:<id>`.
- Перед сетевой отправкой атомарно записывается `pending` в `donation-ledger.json` в каталоге конфигурации плагина OBS.
- Перед POST каждому получателю фиксируется `inflight`; только при подтверждённом ответе ставится `sent`.
- Если ответ неизвестен после сетевого обрыва, запись становится `unknown`; система не делает опасный автоматический повтор.
- При 429 или явно несостоявшемся соединении `Sender` может выполнить ограниченный безопасный повтор.
- При завершении стрима и «Только во время стрима» незавершённые сетевые запросы прерываются; соответствующий статус `unknown`, новые полученные донаты `not_sent_stream_stopped`.
- Тестовая рассылка выполняется напрямую, без затрагивания журнала реальных донатов.
- Все данные журналируются без секретных токенов и полного текста донатерских сообщений.

## Сборка на Windows

Понадобятся Visual Studio 2022 C++, CMake 3.28+, dev-пакеты OBS 30+ x64 и совместимые пакеты **Qt6 Core, Gui, Widgets, Network, WebSockets**.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="C:/path/to/obs-and-qt-cmake-prefixes"
cmake --build build --config RelWithDebInfo
```

Установщик требует DLL Qt WebSockets, собранную под ту же версию Qt, что и OBS:

```powershell
makensis /DPLUGIN_DLL="C:\path\stream-notify.dll" /DQT_WEBSOCKETS_DLL="C:\path\Qt6WebSockets.dll" installer\StreamNotify.nsi
```

Если версия QtWebSockets несовместима с Qt внутри OBS, плагин не загрузится. До раздачи всем пользователям требуется Windows-сборка и тесты на поддерживаемых версиях OBS.

## Необходимые реальные испытания

1. OBS открывается, док-панель работает, анонсы стримов не изменились.
2. DonationAlerts: токен с указанными OAuth scopes, handshake и подписка на `$alerts:donation_ID`.
3. Настоящий новый донат (100/500/2000 RUB), один правильный уровень и сообщение в каждый включённый канал.
4. Входящее тестовое событие или повторный ID не создаёт новый анонс.
5. Недействительный token, API 429, отключение интернета, завершение эфира во время запроса, перезапуск OBS.
6. Локальное сохранение/загрузка DPAPI и индивидуальных порогов каждой валюты.
7. Пользовательский DonatePay-аккаунт: реальный ответ старого/нового API, поля/коды статусов и доступные лимиты.
